# UI の決めごと

「決めていないこと」を無くすための一覧です(IMPROVEMENT_DESIGN_2026-10 の Phase 0)。新しい画面・部品は、ここに合わせてから作ります。
トークンの定義は `src/app/globals.css`。

## 色

| 用途                         | 使うトークン                        | 決めごと                                                 |
| ---------------------------- | ----------------------------------- | -------------------------------------------------------- |
| 操作(リンク・ボタン・選択中) | `--accent-current`                  | 選んだ色から導出。紫(テーマ色)は**操作と選択だけ**に使う |
| アクセント背景の上の文字     | `--on-accent`                       | 必ずこの組み合わせで使う(AAを満たす)                     |
| 正解・確定                   | `--color-accent-green`              | 緑は正解の表示だけ                                       |
| 不正解・失敗                 | `--color-negative`                  | 赤は不正解・未達だけ                                     |
| 本文・補助                   | `--color-ink` / `--color-ink-muted` | 補助文は灰                                               |
| 罫線                         | `--color-line`                      |                                                          |

- ライト/ダークの両方で、アクセントは地色に対して 4.5:1 以上になるよう導出する(`deriveThemeFromColor`)。

## 色見本

- 見本の周囲は常に中立灰(`--swatch-stage` / `--swatch-ink` / `--swatch-paper`)。**テーマ(ライト/ダーク/選択色)で変えない**。周りの色で見え方が変わるため。
- 見本には**必ず名前または値を併記**する。色だけで意味を伝えない。
- 画面上の色は環境により異なる旨を、比較画面とAtlasに固定の注記で出す。

## 文字・数字

- 見出しは「日本語の主題 + 灰色の英字の副題」の2段(`.subtitle`)。
- 数字は**半角・等幅**(`.num` / `--font-num`)。RGB・HSV・Lab は `src/lib/color-format.ts` で固定幅に整え、`white-space: pre` で桁を揃える。
- ラベルの英字(CATALOG、COMPARE など)は大文字・字間広め(`--tracking-caption`)。

## アイコン

- `src/components/icons/Icons.tsx` に集約。24pxグリッド、線幅1.5、`currentColor`、装飾なので `aria-hidden`。
- 意味はラベルが持つ。アイコンだけのボタンは `aria-label` を付ける。

## 画面の型(カタログ・比較・Atlas)

- **左=チップと一覧、中央=主役、下=操作**。共通部品は `EntryList`・`useEntryFilter`。
- 行は「見本 + 名前 + 英字副題 + 値(右揃え・等幅)」。
- 操作は `ActionLink` / `ActionButton`(枠線のみ・ホバーで塗り反転)。
- 900px以下は縦積みにし、主役を一覧より上に出す。

## 動き

- 動きは `prefers-reduced-motion` で止める(`globals.css` の全体ルール + JSで生成する動きは生成しない)。
- 演出は意味を足すものだけ(正答数のフリップ、押した位置の波紋、404の色相)。装飾だけの動きは足さない。

## UIパーツ

指示や実装では、名前に「場所・きっかけ」を添える(例: 「出典パネルを、右から出るドロワーにする」)。

| パーツ | 実装 | 使う場所 | 決めごと |
| --- | --- | --- | --- |
| タブ | `SectionTabs` | 色 / 図形 / 試験対策の切替 | 画面が変わるのでリンク。現在地は `aria-current="page"` |
| チップ | `EntryList` | カテゴリ・系統の絞り込み | 選択中は `aria-pressed` と塗りで示す |
| カルーセル | `RelatedCarousel` | 詳細ページの近い色 | スクロールスナップ+前へ/次へ。並びはΔEの小さい順 |
| ツールチップ | `Tooltip` | 数値ラベル(HEX/RGB/HSV/Lab/ΔE)の説明 | ホバー・フォーカス・タップで開き、Escで閉じる。点線の下線で「説明あり」を示す |
| 目次(スクロールスパイ) | `SectionNav` | 色の詳細ページ | 現在地は文字色と下線(動きは足さない) |

## 動きの上限

- **1画面で使う動きは2種類まで。**
- 通常画面は静かに保つ。装飾だけの動きは足さない。
- 撮影の決定性や安全上限が要る画面では動きを使わない。

| 動き | 実装 | 場所 |
| --- | --- | --- |
| 背景色トランジション | `HueBackdrop` | 色の詳細ページ。背景が色相に応じて薄く染まる(見本の周囲は中立灰のまま) |
| スタッガー | `.stagger` + `--i` | 一覧の行・比較カード・近い色カード(遅延は12番目で頭打ち) |

## テーマ

- `<html data-theme="light|dark">` を描画前の初期化スクリプトが付ける。保存キーは `ce:theme-mode`。
- 色を扱うコンポーネントは、ハードコードせずトークンを使う(見本の色そのものは除く)。
