# 用語集

| 用語 | 意味 |
|---|---|
| **frontmatter** | Markdown の先頭の `---` で囲んだ、構造化データ(YAML)。名前・分類・色の値など |
| **HEX** | `#RRGGBB`。赤・緑・青を 16 進 2 桁ずつで表す。このリポジトリの**正本** |
| **RGB / HSV / HSL** | 色の表し方。光の混ぜ方 / 色相・彩度・明度 / 色相・彩度・輝度 |
| **色相(Hue)** | 色の種類(赤・黄・緑 …)。0〜360° の**周期** |
| **彩度(Saturation)** | 色の鮮やかさ |
| **明度(Value / Lightness)** | 色の明るさ |
| **三属性** | 色相・彩度(鮮やかさ)・明度(明るさ) |
| **Lab(L\*a\*b\*)** | 数の距離が見た目の差に近くなる色空間。L\*=明度・a\*=緑↔赤・b\*=青↔黄 |
| **LCh** | Lab の a\*・b\* を円筒座標にしたもの。C\*=彩度に相当する距離・h=色相角 |
| **ΔE** | 2 色の距離。小さいほど近く見える。ここでは簡易な CIE76 |
| **ガマット(gamut)** | ある色空間(ここでは sRGB)が出せる色の範囲 |
| **sRGB** | 標準的なディスプレイの色空間 |
| **相対輝度** | 人の目の感度で重みづけした明るさ(0〜1) |
| **コントラスト比** | `(明るい方+0.05)/(暗い方+0.05)`。1〜21 |
| **WCAG / AA / AAA** | Web のアクセシビリティの指針 / 基準の段階(通常の文字は 4.5・7) |
| **PCCS** | 日本色研配色体系。トーン(12 種)と色相で色を整理する |
| **トーン** | 明度と彩度を合わせた色の調子(ビビッド・ペール・ダーク …) |
| **色彩検定** | 色の知識を問う検定(1級・2級・3級・UC級) |
| **レジストリ** | id → 対応の表。`id in 表` で、対応があるか調べる |
| **ローダー** | Markdown を読み、メタデータと本文の HTML を返す部品(`createContentLoader`) |
| **App Router** | Next.js の、フォルダがそのままページになるルーティング |
| **ライトナー式** | 箱を使った間隔反復。正解で箱が上がり、次の出題まで間が空く |
| **間隔反復** | 忘れる頃に再出題する学習法 |
| **localStorage** | ブラウザが端末の中に保存する領域。ここでは学習履歴(`ce:review:v1`) |
| **純粋関数** | 同じ入力に同じ出力を返し、外部の状態に触れない関数 |
| **オイラー標数** | 多面体の V−E+F。凸な多面体は 2 |
| **three.js** | ブラウザで 3D を描くライブラリ。「立体」を選んだときに読み込む |
