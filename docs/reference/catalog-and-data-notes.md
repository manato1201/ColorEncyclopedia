# 収録・可視化・数値の詳細(旧 README より移動)

> README を入口に絞るため、旧 README の内容をそのまま移した(相対リンクだけ直した)。入口は [README](../../README.md)。
色彩検定対策兼学習のために色彩・図形に関しての情報を図鑑のように収録し、閲覧できる機能を作るリポジトリです

Next.js 16(App Router)/ React 19 / TypeScript。コンテンツは `content/colors`・`content/shapes` のMarkdown(frontmatter付き)で管理します。

## 主なページ

| パス | 内容 |
| --- | --- |
| `/` | 入口(収録数は実データから算出) |
| `/colors`・`/colors/[id]` | 色図鑑のカタログと詳細(数値データ・方式の比較・コントラスト比) |
| `/shapes`・`/shapes/[id]` | 図形図鑑のカタログと詳細(作図手順の可視化。立体にすると意味が増える図形は「平面 / 立体(3D)」を切り替え) |
| `/atlas` | 色彩Atlas: 色相×彩度、色相×明度(2D)と、全収録色を色立体に置く3D(点をクリックで選択) |
| `/compare`・`/compare/shapes` | 最大4件の比較(`?ids=a,b` で選択済みにできる) |
| `/exam`・`/exam/[level]`・`/exam/review` | 級別の自作問題と、間隔反復による復習 |
| `/basics` | 色の基礎(はじめに) |

## コマンド

```bash
npm run dev          # 開発サーバー
npm run verify       # コンテンツ検証(hex→HSV/Lab再計算、検定問題のid・答え・参照先など)
npm run exam-table   # 下の「試験範囲との対応表」の元になる表を出力
npm run lint
npm run build
```

## 収録と可視化

- 収録数と、可視化に対応している数は、`npm run verify` が出力します(例: `visualizers: 図形 67/67件、色 95/95件が可視化に対応`)。数字をここに手書きしません。
- **図形**の作図手順は、`src/lib/shape-visualizers/` にカテゴリごと(比例・対称性・平面充填・フラクタル・曲線・作図・立体)のジェネレータがあり、全フレームの座標が有限で描画範囲に収まることを `verify` が検査します。
- **色**の可視化は、種類ごとに登録します(`src/lib/color-visualizers.ts`)。色相環・配色(数値を持つ色)、デモ用の色の色相環(色相環・配色理論の概念エントリ)、混色、見え方の場面(対比・残像・進出と後退・膨張と収縮・面積効果・色温度)、パレットの分布、季節の木、コントラスト比。
- **立体(3D)**は three.js で描きます(`src/components/visualizer3d/`)。three.js は「立体」を選んだときに初めて読み込みます。幾何データ(`src/lib/geometry3d/`)は three.js に依存しない純粋な関数で、`npm run verify` が検査します(多面体のオイラー標数、立方体の展開図が35種のうち11種、3次元ヒルベルト曲線の連続性、フラクタルの個数、円錐の切り口の種類、座標の有限性・範囲)。
  - 図形(`src/lib/shape-3d.ts`): 正多面体・オイラーの多面体定理・立方体の展開図を折る・メンガーのスポンジ・カントール塵・シェルピンスキーの四面体・3次元ヒルベルト曲線・球面のひまわり・巻き貝・リサジュー・円錐曲線・球の詰め込み・一葉双曲面・3次元の木・ベジェ・黄金長方形と正二十面体。
  - 色(`src/lib/color-3d.ts`): 数値を持つ色の位置、パレットの散らばり、三属性(HSV円柱)、混色(RGB立方体)、彩度・明度の対比(Lab)。比較画面では選んだ色を同じ色立体に並べます。
  - 色立体は数式で決まるRGB立方体・HSV円柱・Labだけです。PCCS・マンセルの色立体は対応表が要るため計算していません。
- **第2弾の追加(対応が少ないジャンルを重点)**: 図形は立体・多面体(半正多面体・双対・回転体・空間充填など)、作図・定理(チェバ・方べき・トレミー・ヘロン)、フラクタル、曲線、平面充填、対称性。色は、彩度・明度のジャンルにPCCSの12トーン、配色理論に色相差の配色・配色技法・心理補色、光・グレーディングの用語、色覚の多様性。
  - PCCSのトーンの見本は、HSVでの**自作の目安**で、PCCSの正式な値ではありません。色覚のシミュレーションは、一般に使われる近似の変換(Machadoらの行列)による目安で、実際の見え方は個人差が大きい旨を画面に出しています。
  - 凸包から作る立体(`src/lib/geometry3d/hull.ts`)は、頂点座標から面・辺・双対・回転軸を計算し、`npm run verify` が V−E+F=2、正多面体の回転群の位数、空間充填(格子の1点あたりの体積=立体の体積)を検査します。
- 追加した伝統色(34件)には、色彩検定の級を付けていません(出題範囲との対応を確認していないため)。色の値は、資料によって少し違う代表値の1つです。

## 学習履歴(復習)について

- 解答は、この端末のブラウザの `localStorage`(キー `ce:review:v1`)に保存されます。端末を変える・ブラウザのデータを消すと失われるため、`/exam` から JSON で書き出し/読み込みできます。
- 出題間隔はライトナー式の5段階の箱(1日→3日→7日→14日→30日)です。学習の目安であり、記憶の最適値を主張するものではありません。

## 数値について

- HEX・RGB・HSV・Lab は、収録した色のHEXから計算した値です。画面の数値はすべて `src/lib/color-values.ts` の1か所の変換から出し、記載値(frontmatter)との一致は `npm run verify` が同じ関数で確認します。
- 比較画面の「CHROMA」は、同じ明度L*・色相で sRGB に収まる最大のC*(クロマ)を計算して並べます(LCh→sRGBの逆変換と二分探索)。
- 「カラーグレーディング・光の用語」(デュオトーン、ティール&オレンジ、ハイキー、ローキー、モノクロ、フィルムグレイン、逆光、ゴールデンアワー、ブルーアワー)は、映像・撮影の実務の用語です。名前だけを参考に、説明と見本の配色は自作しています。色彩検定の出題範囲としては確認していないため、「実務の用語」バッジで検定対策の項目と区別しています。
- PCCS・マンセルの値は計算で求められない(対応表が必要)ため、数値としては載せていません。
- 画面上の色は、ディスプレイの設定や周囲の明るさで見え方が変わります。
