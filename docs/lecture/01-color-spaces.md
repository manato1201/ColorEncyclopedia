# 第 1 回 色を数にする(HEX・RGB・HSV・HSL)

> 所要時間の目安: 2 時間 / 前提: 第 0 回・16 進数

## この回のゴール

- HEX・RGB・HSV・HSL の**関係**を説明できる。
- HSV で、**色相が 0〜360° の周期**であることを使える。
- 変換で、**丸め**が入る場所と影響を説明できる。

## 1. 4 つの表し方

| 表し方 | 中身 | 向いている使い方 |
|---|---|---|
| **HEX** | `#E60012`(赤・緑・青を 16 進 2 桁ずつ) | CSS・コンテンツの記載 |
| **RGB** | 0〜255 の 3 つ | 画面の光の混ぜ方 |
| **HSV** | 色相(0〜360°)・彩度(%)・明度(%) | 色の**三属性**で考える・色相環 |
| **HSL** | 色相・彩度・輝度(%) | CSS の `hsl()` |

HSV と HSL は、**色相は同じ定義**(RGB の最大・最小から求める)。彩度と「明るさ」の定義が違う。

```javascript
// 実行できる
(async () => {
  const m = await import("./src/lib/color-math.ts");

  console.log("RGB:", m.hexToRgb("#E60012"));
  console.log("HSV:", m.hexToHsv("#E60012"));
  console.log("HSL:", m.hexToHsl("#E60012"));
  console.log("灰色の HSV(色相は 0、彩度 0):", m.rgbToHsv({ r: 128, g: 128, b: 128 }));

  // HSV → HEX(戻す)。色相は周期なので、負でも 360 を超えても同じ色になる
  console.log("純色の赤:", m.hsvToHex({ h: 0, s: 100, v: 100 }));
  console.log("色相 -120° は 240°(青):", m.hsvToHex({ h: -120, s: 100, v: 100 }));
  console.log("色相 480° は 120°:", m.hsvToHex({ h: 480, s: 100, v: 100 }), m.hsvToHex({ h: 120, s: 100, v: 100 }));
  console.log("補色(色相 +180°):", m.hsvToHex({ h: (355 + 180) % 360, s: 100, v: 90 }));
})();
```

```text
# 出力
RGB: { r: 230, g: 0, b: 18 }
HSV: { h: 355, s: 100, v: 90 }
HSL: { h: 355, s: 100, l: 45 }
灰色の HSV(色相は 0、彩度 0): { h: 0, s: 0, v: 50 }
純色の赤: #FF0000
色相 -120° は 240°(青): #0000FF
色相 480° は 120°: #00FF00 #00FF00
補色(色相 +180°): #00E6D2
```

- `rgbToHsv` は、`h`・`s`・`v` を**整数に丸めて**返す(`h` は度、`s`・`v` は %)。**丸めた値から戻すと、元の HEX とは 1 ずれることがある**(往復で完全には戻らない)。
- 無彩色(灰色)は、**最大 = 最小**で、色相が決まらない。**0 にする**。
- `hsvToHex` は、色相を `((h % 360) + 360) % 360` で**周期に直す**(負の値・360 以上でも同じ色)。

## 2. 丸めの影響を確かめる

```javascript
// 実行できる
(async () => {
  const m = await import("./src/lib/color-math.ts");
  let off = 0;
  const samples = [];
  for (let r = 0; r < 256; r += 51) {
    for (let g = 0; g < 256; g += 51) {
      for (let b = 0; b < 256; b += 51) {
        const hex = m.rgbToHex({ r, g, b });
        const back = m.hsvToHex(m.hexToHsv(hex));
        if (back !== hex) {
          off += 1;
          if (samples.length < 3) samples.push(`${hex} → ${back}`);
        }
      }
    }
  }
  console.log("216 色のうち、HSV(整数)を経由すると戻らない色:", off);
  console.log("例:", samples.join(" / "));
})();
```

```text
# 出力
216 色のうち、HSV(整数)を経由すると戻らない色: 18
例: #333399 → #323299 / #336699 → #326699 / #339933 → #329932
```

- だから、**数値の正本は HEX**(frontmatter の `colorValue.hex`)。HSV・Lab は、HEX から**計算した表示用の値**。逆(HSV から HEX を作ってコンテンツに戻す)はしない。

## 確認問題

1. 灰色(`#808080`)の HSV で、色相が 0 になるのは、なぜですか。
2. `hsvToHex` に色相 `-120` を渡すと、何度の色になりますか。
3. HEX → HSV → HEX で、元に戻らないことがあるのは、なぜですか。

## 解答

1. 赤・緑・青が同じ値(最大 = 最小)で、色相が決まらないので、0 と決めている。
2. 240°(青)。`((h % 360) + 360) % 360` で周期に直すから。
3. HSV を整数に丸めて返すので、丸めた値から戻すと 1 ずれることがある。

## まとめ

- HEX が正本。RGB・HSV・HSL は、計算した表示用の値。
- 色相は**周期**(0〜360°)。HSV は整数に**丸める**ので、往復では完全には戻らない。
- 次の回は、**人の見え方に近い**色空間(Lab)。
