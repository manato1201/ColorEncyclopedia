# 第 3 回 読める色か(WCAG のコントラスト比)

> 所要時間の目安: 2 時間 / 前提: 第 2 回

## この回のゴール

- **相対輝度**から、WCAG の**コントラスト比**を求める方法を説明できる。
- AA・AAA の基準(4.5・3・7)の意味を説明できる。
- テーマの色を、**基準を満たすように自動で調整**する考え方を説明できる。

## 1. 相対輝度とコントラスト比

文字と背景の色が**近い**と、読めない。WCAG(Web のアクセシビリティの指針)は、**明るさの比**で、読みやすさを決めます。

- **相対輝度**: 線形にした R・G・B に、**人の目の感度**の重み(`0.2126`・`0.7152`・`0.0722`)をかけて足す。0(黒)〜 1(白)。緑が最も明るく感じる。
- **コントラスト比** = `(明るい方 + 0.05) / (暗い方 + 0.05)`。**1:1**(同じ色)〜 **21:1**(黒と白)。

| 基準 | 通常の文字 | 大きな文字 |
|---|---|---|
| **AA** | 4.5 以上 | 3 以上 |
| **AAA** | 7 以上 | 4.5 以上 |

```javascript
// 実行できる
(async () => {
  const m = await import("./src/lib/color-math.ts");

  console.log("黒と白:", m.contrastRatio("#000000", "#FFFFFF"));
  console.log("同じ色:", m.contrastRatio("#E60012", "#E60012"));
  console.log("順序を入れ替えても同じ:", m.contrastRatio("#000000", "#FFFFFF") === m.contrastRatio("#FFFFFF", "#000000"));

  // 灰色の文字を白の背景に置くと、AA(4.5)ぎりぎりはどこか
  for (const hex of ["#777777", "#767676", "#595959"]) {
    const ratio = m.contrastRatio(hex, "#FFFFFF");
    console.log(hex, ratio.toFixed(2), ratio >= m.WCAG_AA_NORMAL ? "AA を満たす" : "AA を満たさない");
  }
  console.log("基準の値:", m.WCAG_AA_NORMAL, m.WCAG_AA_LARGE, m.WCAG_AAA_NORMAL, m.WCAG_AAA_LARGE);
  console.log("白の相対輝度:", m.relativeLuminance("#FFFFFF"), " 黒:", m.relativeLuminance("#000000"));
})();
```

```text
# 出力
黒と白: 21
同じ色: 1
順序を入れ替えても同じ: true
#777777 4.48 AA を満たさない
#767676 4.54 AA を満たす
#595959 7.00 AA を満たす
基準の値: 4.5 3 7 4.5
白の相対輝度: 1  黒: 0
```

- `#777777` は **4.48 で、AA にわずかに届かない**。`#767676` は 4.54 で届く。**見た目がほとんど同じでも、基準の上と下に分かれる**。
- **WCAG の公式のまま**で、**独自の近似はしない**(コードのコメントにも「アンチパターン」として書いてある)。

## 2. テーマを自動で調整する

画面のテーマ色(`deriveThemeFromColor`)は、利用者が選んだ色を、**地色とカードの上で AA を満たす**ように調整します。

1. 選んだ色が、**そのモードの地色とカードの両方**の上で 4.5 以上なら、そのまま使う。
2. 満たさなければ、**色相を保ったまま明るさだけ**を動かす。ライトは**暗く**(明度 V を下げる)、ダークは**明るく**(V を上げ、最後に彩度 S を下げる)。**最初に AA を満たした色**を採る。
3. **無彩色に近い**(彩度が 12% 未満)か、どう調整しても満たせなければ、**安全な既定のテーマ**に切り替える。
4. アクセント色は、色相を 180° 回した**補色**。

> 判定は、**実際に色が塗られる背景**の上で行う(描画されないダミーの背景は基準にしない)。ライトとダークで**地色が違う**ので、モードごとに判定する。

## 確認問題

1. コントラスト比は、何と何の比ですか。最大はいくつですか。
2. `#777777` と `#767676` で、AA の判定が分かれるのは、なぜですか。
3. テーマの自動調整で、**色相を保つ**のは、なぜですか。

## 解答

1. 明るい方と暗い方の相対輝度(それぞれに 0.05 を足した値)の比。最大は 21(黒と白)。
2. 4.5 を境にしていて、`#777777` は 4.48、`#767676` は 4.54 と、境の両側にあるから。
3. 利用者が選んだ色の「らしさ」(どの色か)を残したまま、読める明るさに直すため。

## まとめ

- コントラスト比 = `(L1+0.05)/(L2+0.05)`。基準は 4.5(AA の通常)・3・7・4.5。
- **公式のまま**使い、独自の近似をしない。
- テーマは、**実際の地色の上で**、色相を保って明るさだけ調整し、無理なら安全な既定へ。
